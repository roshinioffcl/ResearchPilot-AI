# ResearchPilot AI – Evaluation Criteria

## 1. Answer Accuracy
Does the answer correctly address the user's question?

## 2. Faithfulness
Is every factual claim supported by the retrieved document context?

## 3. Citation Accuracy
Do the cited document names and page numbers support the claims?

## 4. Context Retention
Can the system understand follow-up questions using conversation history?

## 5. Abstention
Does the system admit when the uploaded documents don't contain enough information?
